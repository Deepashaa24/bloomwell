# Health & Wellness Tracker - Frontend

React application for the Health & Wellness Tracker.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features

- Modern, mobile-first design with Tailwind CSS
- Protected routes with authentication
- Interactive calendar with cycle predictions
- Data visualization with Recharts
- Responsive navigation

## Environment

The frontend is configured to proxy API requests to `http://localhost:5000` in development mode. See `vite.config.js` for configuration.
